# Marrow

A mobile app that turns useful videos into something you can follow. Share a TikTok or YouTube Shorts video, or an Instagram post, and get back a card with the recipe and grocery list, the workout or the travel plan, linked to the original.

Coming soon on iOS. Website: [marrowapp.xyz](https://marrowapp.xyz).

## How it works

- It reads what's said in the video and what's shown on screen, and turns both into a structured card.
- Each item on the card is checked against the video. Items the video doesn't support are flagged for you to check, and anything it never mentions is marked as missing.

## Built with

React Native, Expo, TypeScript, Supabase, Gemini, SQLite, Jest
